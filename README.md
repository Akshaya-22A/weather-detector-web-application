 🌦️ Weather Detector Web Application
A simple and responsive web application built with HTML, CSS, and JavaScript that allows users to check real‑time weather conditions for any city worldwide.

✨ Features
🔍 Search by city name

🌡️ Displays temperature, humidity, wind speed, and sky status

⚡ Fetches live data from a weather API

🎨 Clean, responsive UI with CSS styling

📱 Works seamlessly across devices

🚀 Tech Stack
HTML → Page structure

CSS → Styling and layout

JavaScript → API integration and dynamic updates

📌 Usage
Enter a city name in the search bar.

Instantly view current weather details.

Enjoy a smooth and interactive experience.
